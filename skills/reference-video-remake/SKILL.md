# 参考风格视频重制

## 核心原则

原视频是内容依据，参考视频是风格依据。最终成片必须保留原视频的人物、声音和表达内容，不得把参考视频的人物、口播、文字、案例或图表直接当作成片内容。

尽量还原参考视频的字体、配色、构图、动画方式和镜头节奏，同时让画面丰富、具有表现力。风格还原不得以牺牲内容准确、画面可读性或口播同步为代价。

## 工作流程

### 1. 准备两条视频

确认哪条是“原视频”、哪条是“参考视频”，并取得两条视频后再开始制作。角色不明确或缺少任意一条时，先向用户确认。

- 用户提供的本地文件或下载后的视频，按当前项目 `AGENTS.md` 的任务目录、时间戳命名及 `ref`/`ouput` 规则保存；所有生成物也遵循该规则。用户另有明确要求时，以用户要求为准。
- 任意一条以链接提供时，先使用 `$yt-dlp` 下载，再继续后续步骤。不得在未下载、未检查文件可用性的情况下假装分析视频。
- 如果 `$yt-dlp` 不可用，明确告知用户，并请其安装该技能或提供本地视频；不要静默换成其他下载流程。
- 读取原视频的实际宽高、时长、帧率和音轨信息。成片宽高必须与原视频一致，不得直接套用参考视频的画幅。

### 2. 确认付费素材费用

任何付费图片、视频、音乐、字体或其他素材在生成或购买前，先说明用途、预计费用及影响价格的数量或时长；只能给出区间时，说明估算依据。等待用户确认后再产生费用。新增付费项目或预计费用明显超出已确认范围时，重新说明并确认。

### 3. 拆解并重新编排

使用 `$hypit` 完成整体制作，并遵循该技能的运行与验证要求。

先拆解参考视频，再设计原视频的改编方案：

1. 分析参考视频的画面布局、字体与字幕样式、配色、构图、动画、转场、配乐、音效和镜头节奏，识别可复用的视觉规则，而不只是截取几个静态画面。
2. 获取原视频的口播文本和时间点，按其实际讲述内容梳理段落、概念、案例与情绪变化。
3. 将参考视频的风格规则映射到原视频的口播节奏。动画、文字、图表和转场在讲到对应概念时出现，不照搬参考视频的时间点。
4. 原视频中如果已有背景音乐，不要重复叠加。
5. 把参考视频中的文字、案例和图表替换为与原视频内容对应的版本。不得编造原视频没有的数据或事实；原视频没有可量化数据时，用概念图、流程图或其他忠实表达方式替代数据图表。
6. 保留原视频的人物、原始声音和表达内容。可以调整画面编排、视觉强调和节奏，但不要替换人物、重新配音或改变原意。
7. 原口播人物出现在小窗口时，按面部位置调整裁切或跟踪，使面部处于小窗口中央，并避免遮挡头顶、下巴或关键表情。逐段检查不同镜头，不能只对齐整个视频画布的中心。
8. 配乐和音效延续参考视频的风格与节奏，同时服从原视频内容，不遮盖或破坏原口播。

生成画面必须贴合原视频内容，不使用无意义的炫技填充时长。

因两条视频的内容或时长不同而需要调整结构、镜头数量、节奏、版式或素材时，作出必要适配，并在制作方案或交付说明中列出实际调整及原因。

### 4. 验收成片

检查实际渲染结果和音轨，至少确认：

- 分辨率与原视频相同，时长完整，没有黑帧、空白场景或缺失素材。
- 原人物、声音和表达内容得到保留，字幕准确且可读，画面元素没有异常遮挡或溢出。
- 动画、图表和转场跟随对应口播，配乐与音效没有盖过人声。
- 所有小窗口口播片段中，人物面部均处于窗口中央。

发现问题先修正再交付，不把未经验证的工程文件当作完成成片。

### 5. 制作封面和四平台发布材料

成片验收后，先制作封面图片，再分别撰写小红书、B站、抖音和微信视频号的标题与文案。开始前读取 [references/publishing.md](references/publishing.md)。

封面、标题和文案必须吸引目标观众、符合平台风格与现行规范，并准确反映成片内容。除用户明确要求外，本流程只生成发布材料，不代替用户登录或发布。

最终交付成片、封面图片、四平台标题与文案，以及必要的内容或时长适配说明；文件均按当前项目 `AGENTS.md` 保存。
